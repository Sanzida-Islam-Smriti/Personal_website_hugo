# Sanzida Islam Smriti — Hugo Portfolio

A dark, animated, recruiter-focused personal portfolio built with Hugo.

## Run locally
1. Install Hugo Extended.
2. Open this folder in a terminal.
3. Run:
   `hugo server -D`
4. Open the local URL shown by Hugo.

## Before publishing
Edit `hugo.toml` and replace:
- `your-email@example.com`
- GitHub URL
- `baseURL`

## Publish
This project is ready for a Hugo-compatible static host such as Render, Netlify, Cloudflare Pages, or GitHub Pages. A `public/` folder is generated by running `hugo`.
